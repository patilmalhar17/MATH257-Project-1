# When Does MANOVA Add Information? An NFL Combine Application and Simulation

Author: Malhar Patil  
Submission date: November 8, 2026

## Project description

This project compares multivariate analysis of variance (MANOVA) with four separate ANOVAs. The data that was used was from NFL Combine measurements for wide receivers from 2004-2023 to compare drafted and undrafted players. A simulation was also used to show a situation where MANOVA detects a significant difference while individual ANOVAs did not.
